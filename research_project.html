Featured Project


  • RAG Assistant
    GitHub Demo video
    • Built a five-stage retrieval-augmented generation pipeline: document ingestion, chunking at 400 characters with 50-character overlap, local sentence-transformer embeddings, top-4 vector retrieval with FAISS, and answer generation through the Claude API.
    • Wrapped the pipeline in a Funix web application that accepts .txt, .csv and .pdf uploads, runs batch evaluation against sample question–answer pairs, and shows the retrieved source chunks alongside every answer.
    • Added token-usage and cost tracking and packaged the system with Docker. Embedding and retrieval run locally, so only generation calls consume API credits.
